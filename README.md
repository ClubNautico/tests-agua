# Tests de agua · Club Náutico

Página para tomar tests de agua en la piscina: cronómetro con salida común, pases y llegada por carril, pulso desde 400 m y varios celulares en el mismo test.

Los datos se guardan en una hoja de Google del club. Esta página no contiene datos de los nadadores; la lista llega del servidor solo después de escribir un ID de test válido.
